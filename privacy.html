Privacy Policy

Bonsai — JSON Tree Viewer  ·  Effective 28 August 2026

Bonsai collects no data. There is no analytics, no telemetry, no tracking, no advertising, no remote server and no remote code. Nothing you view is transmitted anywhere, because Bonsai never sends anything anywhere at all.

What Bonsai is

Bonsai is a Chrome extension that displays JSON documents (including JSONC and JSON Lines / NDJSON) in a read-only, editor-style viewer with a structure tree, search and themes. All parsing and rendering happens locally, inside your browser.

Information we collect

None. Bonsai does not collect, transmit, sell, rent or share any information. Specifically, it does not collect personally identifiable information, health information, financial information, authentication information, personal communications, location, web history, or user activity.

Page content

To display a JSON document, Bonsai necessarily reads the content of the page you are viewing. That content is processed entirely in your browser's memory in order to render the viewer. It is never sent off your device, never written to any server, and never stored by the extension.

What is stored, and where

The only data Bonsai stores is your own preferences — the theme, editor font size and line height, structure-panel layout, and your copy-path preference. These are saved using Chrome's storage.sync so they follow your Chrome profile across your own signed-in devices.

These settings contain no page content and no personal information. They are handled by Chrome, not by us: we operate no server and have no access to them. Removing the extension removes them.

Permissions, and why each is needed

  • storage — saves the preferences described above.
  • activeTab — used only when you explicitly click "Format this page as JSON" in the toolbar popup, and only for the tab you are looking at when you click it.
  • Access to websites — JSON can be served from any domain, so a fixed list of sites is not possible. Bonsai checks whether a page is a JSON document; on any page that is not, it stops immediately without reading or changing anything. A visible control always returns you to the original raw document.

Third parties

Bonsai contacts no third-party services and loads no remote code. All of its code and assets, including its fonts, are bundled inside the extension package. Its open-source components and their licenses are listed in the extension under Settings → "Open-source licenses".

Children

Bonsai is a developer tool and is not directed at children. Since it collects no data at all, it collects no data from children.

Changes to this policy

If this policy ever changes, the revised version will be posted at this address with a new effective date. Bonsai's "collects nothing" design is a deliberate product decision, not a temporary state.
