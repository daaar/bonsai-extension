Bonsai

JSON Tree Viewer

Raw JSON in a browser tab is a wall of text. Bonsai turns it into the view you would get from opening the file in a desktop code editor — folding, a structure tree, real search — without leaving the tab.

Coming to the Chrome Web Store Try it on sample JSON

What it does

  • Takes over JSON pages automatically — when the content type and the body both look like JSON. One click returns you to the raw document, and a toolbar action formats any page on demand.
  • Searches the whole document — case, whole word and regex, with a match count. It reaches folded and off-screen content, which the browser's own find cannot.
  • Structure panel — a navigable tree with type icons and counts. Copy any value, or copy a path as JSONPath, dot or bracket notation, from any row.
  • Reads malformed files too — broken JSON still renders, with the first error marked at its exact line and column instead of a blank page.
  • JSON, JSONC and JSON Lines — NDJSON streams fold into a single array view with a record count.
  • Byte-exact by design — read-only, and copying preserves the original bytes. Number precision, key order and duplicate keys are never rewritten.
  • Dark and light themes — switched live, synced across your Chrome profiles, with adjustable editor type.
  • Local files — works on file:// JSON once you allow file access, or just drop a file into the viewer.

Privacy

Bonsai collects nothing. No analytics, no telemetry, no servers, no remote code — every document is parsed and rendered on your own machine and never leaves it. The only thing stored is your own settings. The full statement is in the privacy policy.
